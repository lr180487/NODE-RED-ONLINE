Descripción**NR ONLINE** es una plataforma de automatización e integración tecnológica basada en Node-RED, diseñada para conectar aplicaciones, servicios web, dispositivos IoT y sistemas industriales.Su arquitectura permite centralizar flujos de automatización, supervisar procesos y facilitar el intercambio de información en tiempo real.## 2. Características- Automatización visual con Node-RED.- Integración con Python FastAPI.- Comunicación en tiempo real mediante WebSocket.- Integración con MQTT.- Comunicación industrial OPC UA.- Integración con PLC Siemens S7-1200.- Supervisión de variables y procesos.- Contenedorización mediante Docker.- Despliegue cloud mediante Fly.io.- Control de versiones mediante GitHub.## 3. Arquitectura```text                 NR ONLINE                      |               WEB DASHBOARD                      |                  NODE-RED                 PORT 1880                      |          +-----------+-----------+          |           |           |        MQTT        OPC UA     WebSocket          |           |           |          +-----------+-----------+                      |                 FASTAPI                 PORT 8000                      |              GATEWAY INDUSTRIAL                      |               PLC SIEMENS                  S7-1200                      |              CONTROL DE PROCESOS```La comunicación industrial se realizará mediante un gateway local seguro, evitando exponer directamente los PLC a Internet.## 4. Tecnologías| Tecnología | Aplicación ||---|---|| Node-RED | Automatización || Python | Backend || FastAPI | API REST || WebSocket | Tiempo real || MQTT | Mensajería IoT || OPC UA | Comunicación industrial || Docker | Contenedores || GitHub | Versionamiento || Siemens S7-1200 | Control industrial || Fly.io | Despliegue cloud |## 5. Requisitos- Windows, Linux o macOS.- Node.js y npm.- Node-RED.- Git.- Docker (opcional).- Python para FastAPI.## 7. Instalación local```bashnpm install -g --unsafe-perm node-red```Ejecutar:```bashnode-red```Acceder:```texthttp://localhost:1880```## 8. DockerConstruir:```bashdocker build -t nr-online .```Ejecutar:```bashdocker run -d --name nr-online -p 1880:1880 -v nr-online-data:/data --restart unless-stopped nr-online```## 9. Integración industrial### OPC UA- Lectura de variables industriales.- Supervisión de procesos.- Intercambio de datos con PLC.- Gestión de estados y alarmas.### MQTT- Comunicación con sensores.- Integración IoT.- Publicación y suscripción de mensajes.### Siemens S7-1200Integración mediante OPC UA o S7 Communication, según las capacidades y configuración del controlador.### FastAPI- Servicios REST.- Autenticación y autorización.- Gestión de dispositivos.- Registro de eventos.- Comunicación WebSocket.## 10. Variables de entornoCrear `.env` a partir de `.env.example`.```envNODE_RED_PORT=1880API_HOST=127.0.0.1API_PORT=8000MQTT_BROKER=localhostMQTT_PORT=1883OPCUA_ENDPOINT=opc.tcp://localhost:4840LOG_LEVEL=info```Los valores son orientativos. Configurar las direcciones y credenciales reales en cada entorno sin publicar secretos.## 11. Despliegue en Fly.ioAutenticación:```powershellfly auth login```Crear aplicación:```powershellfly launch --name nr-online --no-deploy```Desplegar:```powershellfly deploy```Verificar:```powershellfly statusfly logs```Configurar almacenamiento persistente para `/data` y autenticación del editor antes de producción.## 12. Seguridad- Autenticación del editor Node-RED.- Protección de variables de entorno.- HTTPS.- Certificados OPC UA.- Protección de credenciales.- Restricción de acceso a los PLC.- VPN o gateway industrial seguro.- Copias de seguridad de los flujos y datos.No exponer directamente los puertos industriales a Internet.## 14.
